# Proposal

## Why

Калькулятор из `practice-04` выполняет четыре арифметические операции,
но не проверяет аргументы: например, `add("2", 3)` возвращает строку `"23"`.
Нужна одна небольшая brownfield-фича — явная проверка числового ввода.

Статус: **заменено новым scope; не выполнять apply**. Пользователь выбрал
парсер, комплексные числа и историю. Активный пакет:
`specs/001-complex-expression-calculator` от корня практики.
Этот черновик не реализован, не принят и не архивирован как завершённый.

## What Changes

- Все четыре операции принимают только примитивные конечные числа JavaScript.
- Невалидный аргумент вызывает `TypeError("Arguments must be finite numbers")`.
- **BREAKING**: строки, `null`, логические значения, объекты, `NaN` и бесконечности
  больше не приводятся к числам и не участвуют в вычислениях.
- Для допустимых аргументов сохраняются результаты четырёх операций,
  включая дробные и отрицательные числа, и `Error("Division by zero")`.

Не входит: UI, HTTP API, история вычислений, новые операции, округление,
проверка переполнения результата. UI будет отдельной задачей ДЗ.

## Capabilities

### New Capabilities

- `calculator-input`: проверка входа и совместимость арифметических операций.

### Modified Capabilities

Нет: существующих main specs пока нет.

## Impact

`src/calculator.js` и `tests/calculator.test.js` в этой папке.
Исходные код и 7 тестов взяты без изменений из ветки `practice-04`, коммит
`47b8263`. Новые зависимости не нужны. Практика 4 не изменяется.
