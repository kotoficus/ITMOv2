# RAG

**Артефакт Практики 1: `adr.md`**

## 1. Техника и зачем она здесь

RAG ограничивает опору **списком источников** и требует для утверждений ADR ссылку или «Открытый вопрос».

## 2. Вход (фрагмент выбранного артефакта)

Разделы «Контекст», «Решение», «Последствия», схема — нужны явные ссылки.

## 3. Разрешённые источники

| Источник | Зачем |
|---|---|
| `practices/practice_01/TRAINING_PR.diff` | Код контура B |
| `practices/practice_01/README.md` | Учебный кейс, границы помощника |
| `practices/practice_01/context.md` | Context Pack (формат риска) — только как согласованный артефакт курса |
| Иное / «знание FastAPI defaults» | **Не использовать** без пометки «Открытый вопрос» |

## 4. Запрос

```text
Для утверждений в adr.md укажи источник из списка.
Нет источника → «Открытый вопрос». Добавь раздел «Источники (RAG)» только в adr.md.
```

## 5. Ответ со ссылками

См. таблицу «Источники (RAG)» в `adr.md`: эндпоинт/`diff`/`generate` ← diff; формат/запреты ← README; SLA/4xx ← открытый вопрос; `accepted` ← не подтверждено.

## 6. Что приняли / отклонили

- **Приняли:** отдельный раздел источников в ADR.
- **Отклонили:** опору на «типичное поведение FastAPI» как факт продукта.

## 7. Изменение в выбранном артефакте

- Файл: `practices/practice_01/adr.md`
- Раздел: «Источники (RAG)» (+ уточнение таблицы в «Контексте»)
- Что стало: трассировка утверждений к файлам.

## 8. Проверка

Каждая строка раздела «Источники» указывает путь или «Открытый вопрос»; нет новых прод-фактов.
