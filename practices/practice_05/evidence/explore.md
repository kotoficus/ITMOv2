Историческая запись первоначального исследования. Этот scope затем
заменён по решению пользователя; текущий пакет планирования находится в
`../specs/001-complex-expression-calculator/`. Указанные ниже незавершённые
действия относятся к первоначальному предложению.

## Источники и исходное состояние

- Условие: `prenetation.pdf`, 16 слайдов, прочитано извлечением текста через PDFKit.
- В ветке `main` практики 1–2 содержат исходные шаблоны; выполненная практика 4
  находится в отдельной ветке `practice-04`.
- Для продолжения своего проекта в `practice_05` скопированы только
  `src/calculator.js` и `tests/calculator.test.js` из
  `practice-04` (`47b8263:practices/practice_04/`).
  На этапе подготовки оба файла побайтно совпадают с источниками.
- Четыре операции: сложение, вычитание, умножение и деление. Проверяется
  только деление на ноль. Проверки типов аргументов нет.
- Команда baseline: `node --test tests/calculator.test.js`.
  Результат: 7 тестов, 7 успешных, 0 неудачных; вывод в `baseline.txt`.
- OpenSpec установлен во временную папку, версия 1.14.1.
  Инициализация в `practices/practice_05`:
  `openspec init --tools codex --profile core --no-animation`.
  Созданы 6 skills. Корень подтверждён `openspec list --json`.
